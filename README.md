# 🧠 AI Smart Summarizer

An AI-powered Text Summarization Web Application built using Flask and Groq Llama 3. The system generates concise and meaningful summaries from lengthy text while preserving important information. Users can also download the generated summaries in TXT and PDF formats.


## 🚀 Live Demo

🔗 https://nec-crt-project4-text-summarization.onrender.com
---

## 🚀 Features

- ✨ AI-powered text summarization
- ⚡ Fast and accurate summary generation
- 📄 PDF report download
- 📥 TXT file download
- 🎨 Modern responsive user interface
- 🔒 Environment variable support using .env
- 🤖 Groq Llama 3 integration
- 📱 Mobile-friendly design

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Ahammadbi123/NEC_CRT_PROJECT4_TEXT_SUMMARIZATION.git
cd NEC_CRT_PROJECT4_TEXT_SUMMARIZATION
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_groq_api_key
```

### Run Application

```bash
python app.py
```
